CSS FILTERS : These files demonstrate different CSS filter effects used to change the appearance of images. 01_blur.html : - filter: blur() - Makes the image blurry. 02_brightness.html : - filter: brightness() - Increases or decreases brightness. 03_contrast.html : - filter: contrast() - Adjusts the difference between light and dark areas. 04_grayscale.html : - filter: grayscale() - Converts the image to grayscale. 05_sepia.html : - filter: sepia() - Gives the image a warm, vintage look. 06_invert.html : - filter: invert() - Inverts the colors of the image. 07_opacity.html : - opacity - Controls the transparency of the image. Overall, these examples demonstrate how CSS filters can modify the color, brightness, contrast, and appearance of images.
